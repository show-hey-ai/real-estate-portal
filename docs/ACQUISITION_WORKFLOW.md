# 物件取得と再確認の流れ（2026-10-07〜）

ユーザー指定（2026-10-07）：「写真あり優先、再確認の軽量化、0円のキーワード判定」。追加費用はすべて0円です（Apple VisionのOCR、キーワード判定、REINS画面の保存のみ。有料AI・Jevは使わない）。

## 1. 新しく取得する物件

1. REINSで検索し、マイソクPDFを一括でダウンロードする（東京23区、5,000万〜1億円を優先、次に1億円超。図面あり・画像ありで絞る）。
2. **0円のキーワード判定**を実行する。

   ```bash
   npm run screen:maisoku -- --pdf <一括PDF> [--pdf <2つ目のPDF>] --out <非公開フォルダ>
   ```

   - PDFをページ画像にして、Apple VisionのOCRで文字を読み、広告条件の言葉で判定します（25ページで約40秒）。
   - 結果は `<非公開フォルダ>/screening.md` と `screening.json`（所有者のみ読める設定）。データベースには触れません。
   - Codexが作ったOCR結果（`ocr-pages.json`）があれば `--ocr <ocr-pages.json>` でも実行できます。
3. `screening.md` の「作業順」の上から進める。

   | 判定 | 次の作業 |
   | --- | --- |
   | 掲載可の記載あり | 原図面の許可文を目視で確認してから、REINS詳細へ |
   | 要確認（一部不可・選択式・矛盾） | 原図面を目視して判断 |
   | 記載なし | REINS詳細の「広告転載区分」を確認（転載可・広告可なら候補。2026-10-06のユーザー決定） |
   | 承諾・連絡・申請が必要 | 保留。連絡や承諾依頼は送らない |
   | 広告不可 | 除外。表の「根拠」の文字だけ念のため確認 |

   判定は作業の順番を決めるためのものです。**OCRで「広告可」の文字が見つかっただけで掲載してよいことにはしません。** 原図面の目視と、これまでの公開審査（`src/lib/ad-publication-policy.ts`、`src/lib/autonomy/publication.ts`）は今までどおり必須です。

   2026-10-07朝の50ページで、Codexの目視判定と50ページすべて一致しました（掲載可9、記載なし21、承諾等14、不可6）。
4. **写真あり優先**：候補のREINS詳細ページ（画面全体の文字）を1つのフォルダに保存し、並べ替える。

   ```bash
   npm run rank:details -- --dir <REINS詳細を保存したフォルダ> [--out <非公開フォルダ>/details.md]
   ```

   - 並び順：取引中（申込あり・停止中）でないもの → REINSの広告転載区分が許可しているもの → 室内写真が多いもの（登録画像のファイル名で「リビング」「洋室」「浴室」などを数える） → 価格帯（5,000万〜1億円 → 1億円超 → その他）。
   - 原図面に「自社HP可」があり、REINSが「不可」の物件（ユーザー指定で原図面優先）は、screening.md の「掲載可の記載あり」から拾ってください。この一覧ではREINS上「不可」と表示されます。
   - 写真の取得、4言語の文章作成、公開審査は、この順番で進めます。時間が足りない日は、室内写真のない物件を後回しにします。

## 2. 掲載中の物件の再確認

### 毎日（軽い確認）

1. 自動掲載中の物件それぞれについて、**REINSの詳細ページ全体**を保存する（物件番号・価格・広告転載区分・取引状況・変更年月日が入っていること。一部だけ抜き出したファイルでは延長されません）。
2. まず確認だけ実行し、問題なければ `--save` を付けて反映する。

   ```bash
   set -a; source "$HOME/Library/Application Support/Ziyou Portal/autonomy/runtime.env"; set +a
   npm run renew:light -- --dir <今日保存したフォルダ>
   npm run renew:light -- --dir <今日保存したフォルダ> --save
   ```

3. 結果の見方

   | 表示 | 意味 |
   | --- | --- |
   | 延長 | 価格・取引状況・広告転載区分・変更年月日が前回の全面確認と同じ。確認時刻から24時間（最後の全面確認から最長7日）掲載を続ける |
   | 全面確認が必要 | 何か変わった、7日経った、または読み取れない。延長せず、下の全面確認をする（しなければ期限で非表示） |
   | 今すぐ非表示 | 書面による購入申込みあり・紹介停止中など。または `--missing <物件番号,…>` で「REINSで見つからない」と指定したもの |
   | 対象外 | 今日のページがない、6時間より古い、物件番号が違う、すでに期限切れ、手動の物件など |

   - すでに期限が切れた物件は軽い確認では戻せません（全面確認が必要）。**毎朝、最初の期限より前に実行してください。** 朝と夕方の2回実行すると、遅れても切れにくくなります。
   - 反映時は `updatedAt`（サイトマップの更新日）を変えません。内容が変わっていないためです。
   - 「今日確認した」かどうかはファイルの保存時刻で判断します。古いページをコピーして使わないでください。取引状況の行が読めないページでは延長しません。
   - 実行中に止まった場合はもう一度実行してください。止まったjobをworkerが拾っても、REINSのダウンロードは始めずに止めます（`src/lib/autonomy/intake.ts`）。

### 週1回、または変化があったとき（全面確認）

従来どおり、現行の原図面を全ページ目視し、REINS詳細と照合して、通常の公開審査（publication_audit → verify_publication）に通します。軽い確認で「全面確認が必要」と出た物件もこちらです。

## 3. 掲載日

再確認や再公開をしても、物件の掲載日（`publishedAt`）は最初に公開した日のままです（2026-10-07から）。以前は毎日の再確認のたびに掲載日が新しくなり、全物件に「NEW」が付き、新着メールにも全物件が毎週入っていました。
