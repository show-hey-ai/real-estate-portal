# Portal autonomous operations

This implementation applies the operating system in `24-7_v2.pdf` to the existing Ziyou purchase portal. Pages 12–13 are not the product scope. The initial objective, capabilities and spending allowance are configured once; routine source analysis and passing releases do not require a human approval per item. An administrator can pause or change policy from `/admin/autonomy`.

## Implemented loop

| Capability | Execution and evidence |
| --- | --- |
| REINS intake | A dedicated source worker periodically runs the existing REINS browser downloader. A PDF on disk is required. Combined PDFs are split into stable, fingerprinted per-property source jobs. The current bounded download is one search-result page per cycle; existing REINS search settings determine the supply. |
| Automatic decisions | Each source job reserves spending before AI work. Source/price/address/advertising evidence, independent advertising verification, original and translated claims, stable source identity, freshness, privacy and Tokyo public scope are checked by fixed versioned rules. Ambiguous sources stay blocked without routine human approval. |
| Automatic publication | A passing draft is published under a current lease and policy lock. Entire extracted maisoku pages are retained as evidence and unadopted for public media. Public reachability is checked; exhausted verification retries queue a guarded rollback. Later edits are preserved. Automatic releases expire after 24 hours without fresh source renewal. Verified REINS IDs reconcile changed price/facts into the same listing; a verified denial revokes an automatically managed listing. Manual changes/deletions leave durable overrides. A missing stable ID blocks automatic publication. |
| Article generation | Up to three Tokyo ward purchase articles per daily cycle, in Japanese, English and both Chinese variants. The first version uses source-backed templates, not freeform AI prose. It requires three priced public sources and reports the selected listings' asking-price range, median, mix and comparisons. It does not infer transaction prices or ward-wide market prices. Unchanged snapshots are not rewritten. |
| SEO | Generated articles have stable language URLs, canonical/hreflang, Article structured data, source/listing links, discovery via the footer and sitemap. Daily jobs inspect public metadata, robots and sitemap and record article views and observed search referrers. Search rankings/indexing are not fabricated. This is technical and content SEO, not an arbitrary production-code editor or backlink buyer. |
| Improvement | Aggregate supply, traffic, clicks and inquiry stages are observed. The optional AI strategist proposes a labelled hypothesis and chooses a fixed diagnostic capability; it cannot expand permissions, alter quality rules, spend outside the allowance, or claim revenue from lead labels. |
| Recovery | PostgreSQL jobs, unique dedupe keys, atomic cost reservation, leases, bounded retries and release receipts survive restarts. Paid calls with an unknown result are not blindly repeated. One failed capability does not prevent independent free observations. |

## Install and activate

The files alone do not activate production. No production migration, live REINS collection, paid API request, publication or scheduler activation is implied by local tests.

1. Back up the actual production database, reconcile its migration history, and apply the additive autonomy migration while operation remains paused. Existing unrelated migrations must be reconciled before `prisma migrate deploy`. Keep the public listing column projection pending until the compatible application is serving production; older public clients use `select *` and cannot operate with restricted column grants.
2. Configure a deployment-compatible database connection and the source worker environment: database/service credentials, REINS credentials/search settings, `OPENAI_API_KEY`, `IMPORT_ADMIN_USER_ID`, and a persistent private `AUTONOMY_SOURCE_DIR`. For Vercel, copy the IPv4-capable pooler endpoint from Supabase's Connect dialog; do not infer its cluster host from the region. When the platform does not trust the database certificate chain, set `DATABASE_SSL_CA` to the PEM root certificate obtained from that project's database settings. The configured CA path retains certificate and hostname verification and removes competing connection-string SSL options; do not disable certificate verification. Install the Playwright Chromium runtime used by the existing downloader. On the verified Mac integration, set `REINS_HEADLESS=false` to use a minimized standard browser through the official REINS entry page. Source-command logs stay in the private source directory with mode 600.
3. Set the actual site origin with `NEXT_PUBLIC_SITE_URL` (or the existing app URL setting). Provide a random 32+ character `AUTONOMY_CRON_SECRET` on the deployment. Stage the production deployment without switching the public alias, verify both public content and an authenticated paused tick against the actual database, and then promote it. Apply the public listing column projection after promotion and recheck public reads; browser roles lose access to private listing columns, while guarded admin server routes use the service client for private reads. For an optional GitHub clock, install the workflow on the default branch with repository variable `AUTONOMY_ORIGIN` and the same secret. Ensure that branch contains the compatible application before allowing an automatic Git deployment. The clock POSTs the protected endpoint every 15 minutes. Scheduled GitHub actions can be delayed; the durable schedule deduplicates overlapping wakes.
4. Run `npm run autonomy:worker` under a service manager on an always-on machine that has access to REINS. The HTTP worker cannot claim source jobs. A sleeping Mac does not collect REINS. `npm run autonomy:once` performs one bounded local cycle. A service manager must restart the worker after a host/process restart.
5. In `/admin/autonomy`, set the objective, monthly AI allowance, source interval and reservations, enable the desired capabilities, then start. Defaults are paused, zero paid allowance and all optional capabilities off. No amount from the PDF is treated as authorized spending.
6. Confirm the source-worker heartbeat, real downloaded files, source/audit records, actual published-page verification and observed public results before describing production as running 24/7.

Both clocks can operate simultaneously. Only a capable source worker claims REINS/source-import work. Current leases, tenant identity and unique keys prevent concurrent duplicate execution.

## Costs and stopping

The monetary budget is a reservation-based operating allowance, not a verified provider invoice or a guaranteed vendor billing cap. Each source import is one PDF/page, at most eight provider HTTP requests, fixed mini models and bounded output. The source worker disables unbudgeted Jev/Codex fallback calls. Request IDs and token usage are retained privately. The reservation stays charged to its execution month until actual billing is recorded. Unknown paid outcomes retain their reservation across months. Known completed receipts do not consume next month's allowance; invoiced costs remain a separate field. Configure the supplier's own billing controls if a strict invoice cap is required.

Free observations, deterministic article generation and SEO checks can continue when paid work waits for budget. Pausing prevents new claims and guarded mutations. An already dispatched external request can finish; source processes check policy/ownership every five seconds and terminate at a safe boundary. Paid dispatch holds the policy lock while its bounded response is recorded, so a simultaneous configuration request may need to retry. This does not require a human in routine operations; unknown paid outcomes are an exception requiring reconciliation.

## Current limits

REINS source collection uses the existing Playwright integration and one result page per cycle. Authentication changes, CAPTCHA, search limitations or unavailable sessions stop that capability with retained jobs. This version does not submit forms to brokers, send client messages, pay invoices, edit legal guidance without verified sources, or autonomously rewrite/deploy application code. Fixed capabilities improve the live portal through observed data, content and controlled publication.

## Acquisition order and light re-checks — 2026-10-07

The user chose photo-first acquisition, a lighter daily re-check and free keyword screening. All of it costs 0 yen (Apple Vision OCR, keyword rules, saved REINS pages). The working steps are in [ACQUISITION_WORKFLOW.md](./ACQUISITION_WORKFLOW.md).

- `npm run screen:maisoku` screens a bulk maisoku PDF page by page (`src/lib/ad-screening.ts`). It only orders work: a page is skipped as denied only for a clear general prohibition with no own-site exception, and every listing still needs the drawing read by eye and the normal publication checks. On the 50 pages of 2026-10-07 it matched Codex's visual review on every page.
- `npm run rank:details` orders saved REINS detail pages: still available, REINS advertising allowed, room photos (counted from registered image file names), then the user's price range.
- `npm run renew:light` is the daily light re-check (`src/lib/autonomy/light-renewal.ts`). If the price, sales status, advertising field and change date on today's REINS detail page match the last full check, `autonomyValidUntil` moves to 24 hours after the check, never beyond 7 days after the last full check. Anything else waits for the full check (current drawing read in full, normal publication audit), and a purchase application, a pause or a property missing from REINS hides the listing at once. It claims an autonomy job under the policy lock, respects operator overrides and leaves `updatedAt` unchanged.
- `publicationAudit` now keeps a listing's first `publishedAt` when a re-check republishes it. The receipt's `publishedAt` is the release time (equal to `updatedAt`), which is what a rollback matches; a rollback clears `publishedAt` only for a first release.
